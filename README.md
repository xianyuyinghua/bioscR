# bioscR

<!-- badges: start -->
<!-- badges: end -->

`bioscR` provides convenient utilities for single-cell RNA sequencing
analysis in R. Its first function, `doublets_remove()`, detects doublets in a
Seurat object with `scDblFinder`, stores the predictions in cell metadata, and
optionally removes cells that are not classified as singlets.

## Installation

The package is under development and is not yet available from CRAN. After it
has been published to GitHub, install it with:

```r
# install.packages("remotes")
remotes::install_github("xianyuyinghua/bioscR")
```

The doublet-detection workflow relies on Bioconductor packages. If necessary,
install them first:

```r
if (!requireNamespace("BiocManager", quietly = TRUE)) {
  install.packages("BiocManager")
}
BiocManager::install(c(
  "SingleCellExperiment",
  "SummarizedExperiment",
  "scDblFinder"
))
```

## Usage

```r
library(bioscR)

# Detect doublets independently for each sample and retain singlets only.
seu <- doublets_remove(
  seu,
  assay = "RNA",
  sample_col = "sample"
)
```

For a single library, set `sample_col = NULL`. To annotate doublets without
removing cells, set `remove_doublets = FALSE`:

```r
seu <- doublets_remove(
  seu,
  sample_col = NULL,
  remove_doublets = FALSE
)

table(seu$scDblFinder.class)
```

The returned object contains the metadata generated by `scDblFinder`, together
with the logical columns `is_doublet` and `is_singlet`.
